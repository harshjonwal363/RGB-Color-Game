# 🎨 RGB Color Guessing Game

A fun and interactive web-based game where players guess the correct RGB color based on the displayed RGB value.

## 🧠 How It Works
- An RGB color value is displayed (e.g., `rgb(255, 0, 0)`).
- Multiple colored circles appear on the screen.
- Click the circle that matches the RGB value.
- Correct guesses change all circles to the correct color.
- Wrong guesses fade out until you find the right one.

## 🎮 Game Modes
- **Easy** – Fewer color options
- **Hard** – More color options for a tougher challenge

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
